Robbo Konstruktor (by Janusz Pelc) is the construction kit for the game *Robbo*: build your own planets from the
game's elements, play them straight from the editor, arrange them into a game with its own title page, and save it
as a stand-alone Robbo. The program is in Polish; the
[source repository](https://github.com/NowinskiK/lkavalon-atari/tree/main/robbo-konstruktor) has an English
description and glossary ([ABOUT.md](https://github.com/NowinskiK/lkavalon-atari/blob/main/robbo-konstruktor/ABOUT.md))
and the reverse-engineered source code.

Saving a stand-alone game ("zapisz Robbo") formats the disk first. Press **Blank disk** before you save it, then
**Download disk**: the downloaded file boots straight into your game.
